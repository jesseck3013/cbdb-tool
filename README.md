# cbdb-tool

This project has CLI and web interfaces for querying the [China Biographical Database Project (CBDB)](https://cbdb.hsites.harvard.edu/). The tool uses the SQLite format of the database. 

# Similar Projects

This tool is inspired by the following projects.

- [CBDB API](https://cbdb.hsites.harvard.edu/cbdb-api)  
- [CBDB WEB](https://dh-tools.com/cbdb/)  
- [西市独柳·中国历代人物传记](https://people.xishiduliu.com/)
